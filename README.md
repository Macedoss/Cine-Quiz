# Cine-Quiz
OBJETIVO; Jogo de pergunta e respostas sobre cinema, para conhecer seu conhecimento sobre assunto pop e filmes. Trabalho para testar conhecimentos sobre Html, Css e JavaScrpit.

Tecnologias Utilizadas; HTML5, CSS3 e JavaScript;

Instruções de uso; Cadastro de usuario para começar QUIZ interativo de perguntas e respostas, cadastrar "Nome", "Usuario", "Email", "Telefoene", "Genero Preferido".
logo em seguida , escolher opção onde você considera correta em volta da perguntas, no final de tudo será feitos a contagem de pontos e irá mostrar seu ranking, podendo repetir o jogo.
